03 · Projects

Two problems, mapped.

Selected builds where geospatial data meets a full-stack application.

Geo Trip Planner

PILGRIM LOGISTICS
Problem

Pilgrims struggle to plan multi-stop Tirupati trips, choose the right budget tier, and track temple visits without a simple digital flow.

Solution

Budget-based packages, a place picker, an interactive route map, personal temple QR check-in, and an admin visit dashboard.

Outcome

Users plan trips faster and share routes on a live map; staff scan QR codes to log visits; admins see all visitor data in one place.

Stack
FlaskLeafletPostgreSQL / SQLiteOSRMSession Auth

Geo Intel Meta Hub

GEOSPATIAL DATA CATALOG
Problem

Scattered geospatial data — vectors, rasters, LAS point clouds, 3D models — is hard to store, publish, and view in one place.

Solution

A Flask upload pipeline feeds PostGIS and GeoServer, surfaced through a web UI built for search, maps, and 3D viewing.

Outcome

One central catalog serving WMS/WFS layers, rasters, and 3D data — so users discover, preview, and serve layers without leaving the browser.

Stack
FlaskPostGISGeoServerGDAL / PDAL / ogr2ogrCesium
